**Sigma AI — a guided Lean Six Sigma Green Belt suite you run on your own machine.**

All the tools, math, and charts run entirely on your computer and send
nothing anywhere. An optional AI advisor (bring your own Anthropic key)
is the only part that talks to the internet, and only when you use it.

### Download

- **Windows:** the `.msi` (standard installer). If your machine blocks
  `.msi` files, use the `.exe` (NSIS setup) instead — same app.
- **Mac:** the `.dmg` (Apple Silicon). Open it and drag Sigma AI to
  Applications. *Known label bug: the file is named 0.1.0; the app inside
  is 0.2.0 (the Windows filenames and the app itself are stamped
  correctly). Fixed for the next release.*

### Heads-up: the app is not code-signed

This is a personal build with no paid signing certificate, so on first
launch each OS warns you:

- **Windows** shows a blue *"Windows protected your PC"* SmartScreen
  box. Click **More info → Run anyway**.
- **Mac** says the app is from an unidentified developer. **Right-click
  the app → Open**, then confirm.

Both warnings are the OS reacting to the missing signature, not to
anything detected in the app. Full walkthroughs with screenshots:
[Windows](docs/install-windows.md) · [Mac](docs/install-mac.md).

### What's new since v0.1.2

Everything here traces to two operations supervisors with no Six Sigma
training using v0.1 on their own messy spreadsheets on 2026-08-12, and
saying what happened — their verbatim reports, including what went badly,
are in [`docs/uat/`](docs/uat/). Their biggest blockers now have working
controls:

- **You can see your own rows.** A paged rows view with per-column
  totals — and a note saying which totals mean anything.
- **You can fix your own data** without breaking where a number came
  from: merge three spellings of one name into one, join two columns
  into one the Pareto can group by, type a missing row by hand. Every
  edit is versioned; nothing silently overwrites the original.
- **Typing survives walking away.** Drafts persist across navigation.
- **A plain-English front door.** Create a project and import a file
  without first answering the intake quiz.
- **The Pareto chart downloads as a labelled picture** with real
  category names on the axes.
- **The one-page summary is a manager artifact now:** the Pareto is on
  the page, every count names what it counts and over what, empty
  sections say so instead of vanishing, and a provenance footer carries
  the dataset fingerprint.
- **Projects can be deleted** (behind a typed confirmation).
- **Security:** the local engine now refuses requests from other
  websites' pages, and file paths cannot escape the project folder. The
  threat model is stated plainly in [`SECURITY.md`](SECURITY.md).

  `ErrorLog_Sept.xlsx` → Pareto → download the chart as a PNG → produce
  the one-page summary PDF → kill the engine → relaunch → the project
  survives and reopens. All steps passed. Evidence:
  [`docs/uat/clickthrough-2026-08-13/`](docs/uat/clickthrough-2026-08-13/).
- **Windows:** the released `.msi` was installed and launched on real
  hardware (2026-08-13) — installer runs, app launches, engine alive.
- **Mac:** built on a real Mac in CI with the engine smoke-tested inside
  the `.app`, but **no human has run the installed Mac app**. If you're
  the first, your report is wanted either way.
- Not claimed: no user-success statistics. The scorecard counts in the
  repo mean "the controls exist," not "new users succeed with them" — a
  fresh-personas usability test is still ahead.
