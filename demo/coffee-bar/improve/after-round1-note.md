# after-round1.csv — the round-1 pilot-window sample

120 order-to-handoff times in minutes (tenths), collected under the round-1
change (batch milk steaming + marked-cup sequencing, pilot
`pilot-plan-round1.json`) exactly the way the T-11 collection plan collects:
every 4th espresso order, weekday 7:00–10:00 peak, 10 consecutive weekday
mornings 2026-08-10 → 2026-08-21, 12 orders per morning, 6 per daypart. Same
columns as `measure/wait-times.csv` — `order_id`, `date`, `daypart`,
`drink_type`, `barista`, `wait_minutes` — same strata, same operational
definition, same measurement system. The window ends ten days before fall
semester starts, on purpose: round 1 stays clean of the charter's demand
confound.

## The numbers, and the checks made

- n = 120, **mean 6.198**, sd 0.866, min 4.3, max 8.4 — against the
  baseline's 8.408/1.042 and the pilot's pre-declared 7.0 threshold.
- Rows are in true time order (date, then order sequence) — the I-MR
  requirement, and what T-20's before/after run expects.
- **Stability was engine-verified**, not assumed: saved as project dataset
  `7fd6229c7d514253bdb67f950003e68a` (sha256
  `280674e36e87b79991b76e55006d4b8b7f1e33918433025c2d598f5d201c7684`) and run
  through the live `POST /stats/baseline` (USL 5.0, no LSL) on 2026-08-21:
  `stable: true` — "stable: 120 points, no default-rule signal" — I-MR
  limits 3.559 / 6.198 / 8.838, MR UCL 3.242, zero rule-1/rule-4 signals.
- Normality advisory from the same run: `no_concern` (Anderson-Darling
  statistic 0.4443, p ≥ 0.15).
- Capability from the same run, because the window is stable: **Cpk −0.454**
  (Ppk −0.461) against USL 5.0 — better than the baseline's −1.14 and still
  negative. 109 of these 120 orders exceed 5.0 minutes; round 1 moved the
  center, it did not put orders under the customer's line. That number is
  why the remaining-gap loop fires instead of a victory lap.
- Import quality scan on save: 0 missing values, 0 non-numeric values in
  `wait_minutes`, 0 duplicate rows.

The full round-1 verdict — Welch t against the baseline, threshold check,
gap arithmetic, loop routing — is the engine's, recorded in
`proof-round1.json` and `improve-run.md`.

## What round 1 changed on the floor

The mean fell 8.408 → 6.198 because the queue drained faster, and the data's
shape says so in two small ways. The floor of the distribution moved up-left:
the baseline's fastest sampled order was 6.0 minutes; this window's is 4.3 —
a paired latte whose shots pulled while the shared pitcher steamed spends
far less time waiting for the machine to free up. And the spread tightened
(sd 1.042 → 0.866): the old long tail was mostly cups stuck deep in a
one-at-a-time queue, and pairing pulls that tail in. The strata carry the
same story — americanos (no milk, never paired, never waiting on a pitcher)
run fastest, mochas slowest, late mornings a shade slower than early — the
same ordering as the baseline, smaller gaps. Nothing about the sampling
created this: same rule, same tally sheet, same clock.

## Reproducibility

This is demo data: generated by the seeded script below, engineered to tell
the round-1 story the helper content works through (a stable process
re-centered near 6.2 after the batching change) with the same strata
structure as the baseline generator in `measure/dataset-note.md`. The script
searches seeds from 0 and keeps the first sample passing every acceptance
check — mean 6.195–6.205 (so the engine's gap arithmetic lands where the
T-20 helper's worked hypothetical says: ≈2.21 recovered, ≈64.8%, ≈1.20
remaining), sd 0.82–0.95, range inside 4.0–8.9, Anderson-Darling p ≥ 0.06,
and no I-MR rule-1/rule-4 signal (the engine's frozen defaults, same
d2 = 1.128 arithmetic). **Seed 36** is the first acceptable seed and
produced this file. The binding verdicts remain the live engine's
(`/stats/baseline` above, and the T-20 proof), which this file was run
through after generation. Run with `engine/.venv/bin/python` (scipy needed
for the normality pre-check).

```python
#!/usr/bin/env python3
"""Generate demo/coffee-bar/improve/after-round1.csv -- 120 order-to-handoff
times (minutes, tenths) over the 10 weekday pilot mornings 2026-08-10 to
2026-08-21, under the round-1 change (batch milk steaming + marked-cup
sequencing), mean ~= 6.20, STABLE under the engine's default I-MR rules
(rule 1 + rule 4). Same acceptance-search shape as the baseline generator
(measure/dataset-note.md): seeds searched from 0, first seed passing every
check wins; the binding verdict is still the live engine's /stats/baseline,
which this dataset is verified against after generation. Run with
engine/.venv/bin/python (scipy is used for a normality pre-check)."""
import csv
import statistics
import sys
import random

from scipy import stats as scistats

DATES = ["2026-08-10", "2026-08-11", "2026-08-12", "2026-08-13", "2026-08-14",
         "2026-08-17", "2026-08-18", "2026-08-19", "2026-08-20", "2026-08-21"]
ORDERS_PER_DAY = 12  # every 4th espresso order of ~48 -> 6 early + 6 late
DRINKS = ["latte", "cappuccino", "americano", "mocha"]
DRINK_WEIGHTS = [0.40, 0.25, 0.20, 0.15]
# Milk drinks benefit most from pairing; americano never waits on the pitcher.
DRINK_EFFECT = {"latte": -0.05, "cappuccino": 0.05, "americano": -0.30, "mocha": 0.25}
BARISTAS = ["Marcus", "Riley"]
BARISTA_WEIGHTS = [0.6, 0.4]
BARISTA_EFFECT = {"Marcus": -0.08, "Riley": 0.12}
DAYPART_EFFECT = {"early": -0.15, "late": 0.15}
BASE_MEAN = 6.22          # intercept; weighted strata effects net ~-0.02
NOISE_SD = 0.85
DAY_SD = 0.10             # slow day-to-day drift
CLIP_LO, CLIP_HI = 4.0, 8.9
D2_N2 = 1.128             # engine's I-MR d2 constant (stats/constants.py)


def simulate(seed):
    rng = random.Random(seed)
    rows = []
    for date in DATES:
        day_shift = rng.gauss(0.0, DAY_SD)
        for i in range(ORDERS_PER_DAY):
            daypart = "early" if i < 6 else "late"
            drink = rng.choices(DRINKS, weights=DRINK_WEIGHTS)[0]
            barista = rng.choices(BARISTAS, weights=BARISTA_WEIGHTS)[0]
            mu = (BASE_MEAN + day_shift + DAYPART_EFFECT[daypart]
                  + DRINK_EFFECT[drink] + BARISTA_EFFECT[barista])
            x = rng.gauss(mu, NOISE_SD)
            while not (CLIP_LO <= x <= CLIP_HI):
                x = rng.gauss(mu, NOISE_SD)
            order_id = f"POS-{date[5:7]}{date[8:10]}-{i + 1:02d}"
            rows.append([order_id, date, daypart, drink, barista, round(x, 1)])
    return rows


def imr_rule1_rule4_clean(values):
    xbar = statistics.fmean(values)
    mrs = [abs(values[i] - values[i - 1]) for i in range(1, len(values))]
    sigma = (sum(mrs) / len(mrs)) / D2_N2
    ucl, lcl = xbar + 3 * sigma, xbar - 3 * sigma
    if any(v > ucl or v < lcl for v in values):
        return False
    run_side, run_len = 0, 0
    for v in values:
        side = 1 if v > xbar else (-1 if v < xbar else 0)
        run_len = run_len + 1 if side == run_side and side != 0 else (1 if side else 0)
        run_side = side
        if run_len >= 8:
            return False
    return True


def acceptable(values):
    mean = statistics.fmean(values)
    sd = statistics.stdev(values)
    ad_p = scistats.anderson(values, dist="norm", method="interpolate").pvalue
    return (6.195 <= mean <= 6.205 and 0.82 <= sd <= 0.95
            and min(values) >= CLIP_LO and max(values) <= CLIP_HI
            and ad_p >= 0.06 and imr_rule1_rule4_clean(values))


def main(out_path):
    for seed in range(20000):
        rows = simulate(seed)
        values = [r[5] for r in rows]
        if acceptable(values):
            break
    else:
        sys.exit("no acceptable seed found in range(20000)")
    with open(out_path, "w", newline="") as f:
        w = csv.writer(f)
        w.writerow(["order_id", "date", "daypart", "drink_type", "barista", "wait_minutes"])
        w.writerows(rows)
    mean, sd = statistics.fmean(values), statistics.stdev(values)
    over5 = sum(1 for v in values if v > 5.0)
    print(f"seed={seed} n={len(values)} mean={mean:.4f} sd={sd:.4f} "
          f"min={min(values)} max={max(values)} over5={over5}")


if __name__ == "__main__":
    main(sys.argv[1] if len(sys.argv) > 1 else "after-round1.csv")
```
