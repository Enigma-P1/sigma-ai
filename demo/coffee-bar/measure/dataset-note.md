# wait-times.csv — the Measure-phase baseline sample

120 order-to-handoff times in minutes (tenths), collected exactly the way
`collection-plan.json` says: every 4th espresso order, weekday 7:00–10:00
peak, 10 consecutive weekday mornings 2026-07-20 → 2026-07-31, 12 orders per
morning. Columns: `order_id` (POS ticket), `date`, `daypart` (early = 7:00–8:30,
late = 8:30–10:00), `drink_type`, `barista`, `wait_minutes` — the three strata
columns are the plan's three stratification factors, recorded per row so
Analyze can split without re-collecting.

## The numbers, and the checks made

- n = 120, **mean 8.408**, sd 1.042, min 6.0, max 11.1 — consistent with the
  charter's 8.4-minute Q2 magnitude and its 1.1-minute planning SD.
- Rows are in true time order (date, then order sequence), which is what an
  I-MR chart requires.
- **Stability was engine-verified**, not assumed: the saved dataset run
  through the live engine's `POST /stats/baseline` (USL = 5.0, no LSL) comes
  back `stable: true` — "stable: 120 points, no default-rule signal" — zero
  Western Electric rule-1/rule-4 signals, I-MR limits 5.418 / 8.408 / 11.399.
  No hand adjustment was needed after engine verification.
- Normality advisory from the same run: `no_concern` (Anderson-Darling
  statistic 0.2126, p ≥ 0.15).
- Import quality scan on save: 0 missing values, 0 non-numeric values in
  `wait_minutes`, 0 duplicate rows.
- Ten of these rows (picked to span 6.0–11.1) are the re-timed items in
  `msa-study.json`; each first reading there matches this file's recorded
  value for the same `order_id`.

The full baseline verdict — capability indices included — is recorded in
`baseline-run.md`.

## Reproducibility

This is demo data: it was generated by the seeded script below, engineered to
tell the charter's true story (a stable process centered at 8.4 minutes) with
realistic strata structure. The script searches seeds from 0 and keeps the
first sample passing every acceptance check — mean 8.36–8.44, sd 0.95–1.25,
range inside 5.9–11.4, ≥112/120 points within 6–11, Anderson-Darling p ≥ 0.06,
and no I-MR rule-1/rule-4 signal (the engine's frozen defaults, same d2 =
1.128 arithmetic). **Seed 5** is the first acceptable seed and produced this
file. The binding verdicts remain the live engine's, which this file was run
through after generation. Run with `engine/.venv/bin/python` (scipy needed for
the normality pre-check).

```python
#!/usr/bin/env python3
"""Generate demo/coffee-bar/measure/wait-times.csv -- 120 order-to-handoff
times (minutes, tenths) over 10 weekday mornings, mean ~= the charter's 8.4,
STABLE under the engine's default I-MR rules (rule 1 + rule 4). The script
searches seeds from 0 and keeps the first one whose sample passes every
acceptance check below; the binding stability verdict is still the live
engine's /stats/baseline, which this dataset was verified against.
Run with engine/.venv/bin/python (scipy is used for a normality pre-check).
"""
import csv
import math
import random
import statistics
import sys

from scipy import stats as scistats

DATES = ["2026-07-20", "2026-07-21", "2026-07-22", "2026-07-23", "2026-07-24",
         "2026-07-27", "2026-07-28", "2026-07-29", "2026-07-30", "2026-07-31"]
ORDERS_PER_DAY = 12  # every 4th espresso order of ~48 -> 6 early + 6 late
DRINKS = ["latte", "cappuccino", "americano", "mocha"]
DRINK_WEIGHTS = [0.40, 0.25, 0.20, 0.15]
DRINK_EFFECT = {"latte": 0.0, "cappuccino": 0.05, "americano": -0.35, "mocha": 0.25}
BARISTAS = ["Marcus", "Riley"]
BARISTA_WEIGHTS = [0.6, 0.4]
BARISTA_EFFECT = {"Marcus": -0.10, "Riley": 0.15}
DAYPART_EFFECT = {"early": -0.20, "late": 0.20}
BASE_MEAN = 8.42          # intercept; weighted strata effects net ~-0.02
NOISE_SD = 1.00
DAY_SD = 0.12             # slow day-to-day drift (staffing, weather)
CLIP_LO, CLIP_HI = 5.9, 11.4
D2_N2 = 1.128             # engine's I-MR d2 constant (stats/constants.py)


def simulate(seed):
    rng = random.Random(seed)
    rows = []
    for date in DATES:
        day_shift = rng.gauss(0.0, DAY_SD)
        for i in range(ORDERS_PER_DAY):
            daypart = "early" if i < 6 else "late"
            drink = rng.choices(DRINKS, weights=DRINK_WEIGHTS)[0]
            barista = rng.choices(BARISTAS, weights=BARISTA_WEIGHTS)[0]
            mu = (BASE_MEAN + day_shift + DAYPART_EFFECT[daypart]
                  + DRINK_EFFECT[drink] + BARISTA_EFFECT[barista])
            x = rng.gauss(mu, NOISE_SD)
            while not (CLIP_LO <= x <= CLIP_HI):
                x = rng.gauss(mu, NOISE_SD)
            order_id = f"POS-{date[5:7]}{date[8:10]}-{i + 1:02d}"
            rows.append([order_id, date, daypart, drink, barista, round(x, 1)])
    return rows


def imr_rule1_rule4_clean(values):
    """The engine's frozen default I-MR rules (stats/imr.py): rule 1 = any
    point beyond xbar +/- 3*(MRbar/d2); rule 4 = 8+ consecutive points on
    one side of xbar. True only when neither fires."""
    xbar = statistics.fmean(values)
    mrs = [abs(values[i] - values[i - 1]) for i in range(1, len(values))]
    sigma = (sum(mrs) / len(mrs)) / D2_N2
    ucl, lcl = xbar + 3 * sigma, xbar - 3 * sigma
    if any(v > ucl or v < lcl for v in values):
        return False
    run_side, run_len = 0, 0
    for v in values:
        side = 1 if v > xbar else (-1 if v < xbar else 0)
        run_len = run_len + 1 if side == run_side and side != 0 else (1 if side else 0)
        run_side = side
        if run_len >= 8:
            return False
    return True


def acceptable(values):
    mean = statistics.fmean(values)
    sd = statistics.stdev(values)
    in_band = sum(1 for v in values if 6.0 <= v <= 11.0)
    ad_p = scistats.anderson(values, dist="norm", method="interpolate").pvalue
    return (8.36 <= mean <= 8.44 and 0.95 <= sd <= 1.25
            and min(values) >= CLIP_LO and max(values) <= CLIP_HI
            and in_band >= 112 and ad_p >= 0.06
            and imr_rule1_rule4_clean(values))


def main(out_path):
    for seed in range(2000):
        rows = simulate(seed)
        values = [r[5] for r in rows]
        if acceptable(values):
            break
    else:
        sys.exit("no acceptable seed found in range(2000)")
    with open(out_path, "w", newline="") as f:
        w = csv.writer(f)
        w.writerow(["order_id", "date", "daypart", "drink_type", "barista", "wait_minutes"])
        w.writerows(rows)
    mean, sd = statistics.fmean(values), statistics.stdev(values)
    print(f"seed={seed} n={len(values)} mean={mean:.3f} sd={sd:.3f} "
          f"min={min(values)} max={max(values)}")


if __name__ == "__main__":
    main(sys.argv[1] if len(sys.argv) > 1 else "wait-times.csv")
```
