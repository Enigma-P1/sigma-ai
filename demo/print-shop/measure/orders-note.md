# orders.csv — the Measure-phase baseline census

1,566 orders, one row per order presented at the QC desk, collected exactly
the way `collection-plan.json` says: every produced order, both shifts, 21
consecutive service days (Mon–Sat) 2026-06-29 → 2026-07-22 — a census of the
window, not a sample, because proportions need the n a sample this size can't
give (the plan's engine-computed floor is n = 1399). Columns: `order_id`,
`date`, `shift` (day/evening), `order_type`, then the four named checks as
0/1 flags — `trim_misalign`, `wrong_paper`, `ink_smudge`, `wrong_quantity` —
and `reject_any` (1 if any check failed: the defective-order flag every
downstream tool aggregates). An order can fail more than one check: the flags
are the reject log's tally marks (defects), `reject_any` is the defective
unit — the distinction EXIT-11 is about, carried in the data itself.

## The numbers, and the checks made

- n = 1,566 orders (achieved, against the plan's 1,500 — no shortfall), 135
  rejected at first presentation, **pooled p̂ = 0.0862** — consistent with the
  charter's 8.6% Q2 reject-log magnitude.
- 139 failed-check marks on those 135 rejected orders: four orders failed two
  checks each. Flag sums per check: trim_misalign 67, wrong_paper 50,
  ink_smudge 13, wrong_quantity 9 — exactly the check sheet's transcribed
  tallies, because both come from the same reject log.
- Daily subgroup sizes vary 58–90 (Mondays heavy, Saturdays light) — the
  variable n is the point: every p-chart limit in `baseline-pchart.json` is
  that day's own.
- **Stability was engine-verified, not assumed**: the daily aggregates run
  through `POST /artifacts/T-21/validate` with `freeze_requested: true` came
  back frozen — 21 subgroups (≥ 20 floor), **zero rule-1/rule-4 signals** —
  p̄ 0.086207 with per-day limits; the worst day (2026-07-13, 12.8%) sits
  inside its own UCL (17.7%). Full verdict in `baseline-note.md`.
- Import quality scan on save (engine echo): 0 missing values, 0 non-numeric
  values in any numeric column, 0 duplicate rows, 1,566 rows.
- Saved as project dataset `3122dfa39994454090c24e7a857d18f6`, sha256
  `b6b0559d9dd3d9b4ade0e345919929e5741461cd21490fb63c85c93028154d9f` — the
  hash the baseline chart's `source` block and the proof's before-window
  carry, so a reviewer can re-hash the stored file and confirm the chain.
- Rows are in true collection order (date, then presentation sequence) —
  what a control chart's run rules require.
- The reject calls in these rows were made under the arm's-length /
  exactly-2mm operational definition — the one that passed kappa round 2
  (`msa-round2.json`); rounds 1 and 2 ran on the June pre-study set, which
  is why those 50 `PO-06xx` items are not rows in this file.

## Reproducibility

This is demo data: it was generated by the seeded script below, engineered to
tell the charter's true story — a stable ~8.6% defective rate whose
failed-check marks concentrate on trim and wrong paper, then a deliberate
2026-08-03 change that cuts exactly those two — with realistic day-of-week
volume, a two-shift split, and a fall-term surge in the final post-change
week. One simulation produces every window the demo uses: the baseline
census (this file), the nine pre-change monitoring days, the six bedding-in
days, and the 24-day post-change window (which ships as daily aggregates in
the chart/proof artifacts, not as a second CSV). The script searches seeds
from 0 and keeps the first passing every acceptance check: baseline p̄ in
0.082–0.092 with no rule-1/rule-4 signal (the engine's frozen defaults,
mirrored exactly, per-day limits included), trim > paper > ink > quantity
with trim + paper crossing 80% cumulative, a defect-type × shift table that
clears Cochran's rule and reads honestly non-significant (the generator has
no shift effect — the check is that the seed is representative of that
truth), a quiet 30-day pre-change monitoring stretch against the frozen
limits, every post-change day below the frozen center (so the improvement
fires exactly one maximal rule-4 run), a clean post window that can freeze
its own limits, a two-week post slice that clears the proportion floors, and
a visible final-week surge. **Seed 90** is the first acceptable seed and
produced this file plus `summary.json` (the aggregate tables the artifacts
carry). The binding verdicts remain the live engine's, which every number
was run through after generation. Run with `engine/.venv/bin/python` (scipy
for the chi-square pre-check).

```python
#!/usr/bin/env python3
"""Generate demo/print-shop/measure/orders.csv (baseline window, order-level)
plus the daily/step/tally aggregates every Print Shop artifact carries --
one seeded simulation, engineered to tell the story's true mechanism (a
stable ~8.6% first-presentation defect rate whose occurrences concentrate
on trim + wrong paper, then a deliberate process change that cuts exactly
those two), with the binding verdicts always the live engine's. The script
searches seeds from 0 and keeps the first sample passing every acceptance
check below (all mirroring the engine's own frozen p-chart rules and
Cochran/Pareto conventions); run with engine/.venv/bin/python (scipy for
the chi-square pre-check).
"""
import csv
import json
import math
import random
import sys

from scipy import stats as scistats

# --- calendar: Mon-Sat service days ------------------------------------------
def service_days(start_iso, n_days):
    import datetime as dt
    d = dt.date.fromisoformat(start_iso)
    out = []
    while len(out) < n_days:
        if d.weekday() != 6:  # closed Sundays
            out.append(d.isoformat())
        d += dt.timedelta(days=1)
    return out

BASELINE_DATES = service_days("2026-06-29", 21)   # -> 2026-07-22
INTERIM_DATES  = service_days("2026-07-23", 9)    # -> 2026-08-01 (pre-change monitoring)
RAMP_DATES     = service_days("2026-08-03", 6)    # -> 2026-08-08 (change bedding in)
POST_DATES     = service_days("2026-08-10", 24)   # -> 2026-09-05 (post-change window)

# --- process model -----------------------------------------------------------
# Per-order probability of failing each of the four named checks (independent).
BASE_P = {"trim_misalign": 0.042, "wrong_paper": 0.032, "ink_smudge": 0.010, "wrong_quantity": 0.007}
# The fix (prepress pre-flight checklist + labeled paper trays, 2026-08-03)
# targets the vital few only: retention multipliers on the two targeted checks.
RETENTION = {"trim_misalign": 0.35, "wrong_paper": 0.25, "ink_smudge": 1.0, "wrong_quantity": 1.0}
CHECKS = list(BASE_P)

DOW_BASE_N = {0: 82, 1: 76, 2: 74, 3: 72, 4: 78, 5: 62}  # Mon..Sat
SHIFT_SPLIT = 0.58  # P(day shift)
ORDER_TYPES = ["course-packet", "flyer-poster", "program-booklet", "other"]
ORDER_TYPE_W = [0.34, 0.27, 0.22, 0.17]
SURGE_DATES = set(POST_DATES[18:])  # final week: fall-term start surge
SURGE_FACTOR = 1.16

# In-shop rework rates per step (job travelers: not-first-pass at that step,
# caught and fixed in-shop -- the hidden factory the four escape checks don't see).
STEP_P = {"order entry": 0.028, "prepress": 0.048, "print": 0.062, "trim/finish": 0.045}


def day_n(rng, date_iso, phase):
    import datetime as dt
    dow = dt.date.fromisoformat(date_iso).weekday()
    n = rng.gauss(DOW_BASE_N[dow], 6.0)
    if date_iso in SURGE_DATES:
        n *= SURGE_FACTOR
    return max(58, min(97, round(n)))


def check_p(check, phase, ramp_index=None):
    base = BASE_P[check]
    if phase in ("baseline", "interim"):
        return base
    ret = RETENTION[check]
    if phase == "post":
        return base * ret
    lam = (6 - ramp_index) / 7.0  # ramp: 6 days sliding toward full retention
    return base * (ret + (1 - ret) * lam)


def simulate(seed):
    rng = random.Random(seed)
    orders = []  # baseline order rows only (the shipped CSV)
    daily = []   # every phase: per-day aggregates
    for phase, dates in (("baseline", BASELINE_DATES), ("interim", INTERIM_DATES),
                         ("ramp", RAMP_DATES), ("post", POST_DATES)):
        for di, date in enumerate(dates):
            n = day_n(rng, date, phase)
            defectives = 0
            occ = {c: {"day": 0, "evening": 0} for c in CHECKS}
            for i in range(n):
                shift = "day" if rng.random() < SHIFT_SPLIT else "evening"
                otype = rng.choices(ORDER_TYPES, weights=ORDER_TYPE_W)[0]
                flags = {c: int(rng.random() < check_p(c, phase, di)) for c in CHECKS}
                rej = int(any(flags.values()))
                defectives += rej
                for c in CHECKS:
                    if flags[c]:
                        occ[c][shift] += 1
                if phase == "baseline":
                    orders.append({
                        "order_id": f"PO-{date[5:7]}{date[8:10]}-{i + 1:03d}",
                        "date": date, "shift": shift, "order_type": otype,
                        **{c: flags[c] for c in CHECKS}, "reject_any": rej,
                    })
            daily.append({"phase": phase, "date": date, "n": n, "defectives": defectives, "occ": occ})
    return orders, daily


# --- engine-rule mirrors (binding verdicts stay the live engine's) -----------
def p_chart_clean(subs, pbar=None, allow_rule4=False):
    """Mirror stats/p_chart.py rule1 (per-point limits) + imr rule4 (8 same side)."""
    if pbar is None:
        pbar = sum(d for _, d in subs) / sum(n for n, _ in subs)
    for n, d in subs:
        sp = 3 * math.sqrt(pbar * (1 - pbar) / n)
        if d / n > min(pbar + sp, 1.0) or d / n < max(pbar - sp, 0.0):
            return False
    if not allow_rule4:
        side, run = 0, 0
        for n, d in subs:
            s = 1 if d / n > pbar else (-1 if d / n < pbar else 0)
            run = run + 1 if (s == side and s != 0) else (1 if s else 0)
            side = s
            if run >= 8:
                return False
    return True


def acceptable(orders, daily):
    base = [r for r in daily if r["phase"] == "baseline"]
    interim = [r for r in daily if r["phase"] == "interim"]
    ramp = [r for r in daily if r["phase"] == "ramp"]
    post = [r for r in daily if r["phase"] == "post"]
    N = sum(r["n"] for r in base)
    D = sum(r["defectives"] for r in base)
    pbar = D / N
    if not (0.082 <= pbar <= 0.092):
        return False
    # frozen-window cleanliness (engine freeze floor: >=20 subgroups, no rule1/rule4)
    if not p_chart_clean([(r["n"], r["defectives"]) for r in base]):
        return False
    # occurrence Pareto: trim > paper > ink > quantity, trim alone < 80%,
    # trim+paper >= 80% (engine vital-few convention), tail cells usable
    occ_tot = {c: sum(r["occ"][c]["day"] + r["occ"][c]["evening"] for r in base) for c in CHECKS}
    t, p, i, q = (occ_tot[c] for c in ("trim_misalign", "wrong_paper", "ink_smudge", "wrong_quantity"))
    tot = t + p + i + q
    if not (t > p > i > q and q >= 9 and t / tot < 0.80 <= (t + p) / tot):
        return False
    # chi-square defect-type x shift: generated under a true null; keep a seed
    # whose table clears Cochran (>=80% cells expected>=5, none <1) and reads
    # comfortably non-significant, i.e. representative of the generating truth
    table = [
        [sum(r["occ"][c]["day"] for r in base), sum(r["occ"][c]["evening"] for r in base)]
        for c in CHECKS
    ]
    exp = scistats.contingency.expected_freq(table)
    flat = [e for row in exp for e in row]
    if sum(1 for e in flat if e >= 5) < 7 or min(flat) < 1:
        return False
    chi2, pval, dof, _ = scistats.chi2_contingency(table, correction=False)
    if pval < 0.15:
        return False
    # pre-change monitoring (baseline + interim) stays quiet vs FROZEN pbar
    prefix = [(r["n"], r["defectives"]) for r in base + interim]
    if not p_chart_clean(prefix, pbar=pbar):
        return False
    # every post-change day (ramp + post) sits below the frozen center, so the
    # improvement fires exactly one maximal rule-4 run on the monitoring chart
    if not all(r["defectives"] / r["n"] < pbar for r in ramp + post):
        return False
    # post window: own-limits clean (for the recalculated freeze) and on story
    Np = sum(r["n"] for r in post)
    Dp = sum(r["defectives"] for r in post)
    if not (0.034 <= Dp / Np <= 0.046):
        return False
    if not p_chart_clean([(r["n"], r["defectives"]) for r in post]):
        return False
    # first two post weeks: the pre-declared T-17 comparison
    N2 = sum(r["n"] for r in post[:12])
    D2 = sum(r["defectives"] for r in post[:12])
    if not (0.032 <= D2 / N2 <= 0.048 and D2 >= 25):
        return False
    z_p = 2 * (1 - scistats.norm.cdf(abs((pbar - D2 / N2) / math.sqrt(
        ((D + D2) / (N + N2)) * (1 - (D + D2) / (N + N2)) * (1 / N + 1 / N2)))))
    if z_p > 0.005:
        return False
    # surge week visible: final 6 post days ~>=10% busier than the first 18
    if sum(r["n"] for r in post[18:]) / 6 < 1.10 * (sum(r["n"] for r in post[:18]) / 18):
        return False
    return True


def step_counts(rng, n_orders):
    return {s: sum(1 for _ in range(n_orders) if rng.random() < p) for s, p in STEP_P.items()}


def main(out_dir):
    for seed in range(4000):
        orders, daily = simulate(seed)
        if acceptable(orders, daily):
            break
    else:
        sys.exit("no acceptable seed found in range(4000)")

    # per-step in-shop rework counts, from the same seed stream (travelers)
    rng = random.Random(10_000 + seed)
    base_n = sum(r["n"] for r in daily if r["phase"] == "baseline")
    steps = step_counts(rng, base_n)

    with open(f"{out_dir}/orders.csv", "w", newline="") as f:
        w = csv.DictWriter(f, fieldnames=list(orders[0]))
        w.writeheader()
        w.writerows(orders)

    base = [r for r in daily if r["phase"] == "baseline"]
    occ_tot = {c: sum(r["occ"][c]["day"] + r["occ"][c]["evening"] for r in base) for c in CHECKS}
    table = [[sum(r["occ"][c]["day"] for r in base), sum(r["occ"][c]["evening"] for r in base)] for c in CHECKS]
    summary = {
        "seed": seed, "step_rework": steps, "baseline_occurrences": occ_tot,
        "defect_by_shift_table": {"rows": CHECKS, "cols": ["day", "evening"], "observed": table},
        "daily": daily,
        "totals": {ph: {"n": sum(r["n"] for r in daily if r["phase"] == ph),
                        "defectives": sum(r["defectives"] for r in daily if r["phase"] == ph)}
                   for ph in ("baseline", "interim", "ramp", "post")},
    }
    with open(f"{out_dir}/summary.json", "w") as f:
        json.dump(summary, f, indent=2)
    t = summary["totals"]
    print(f"seed={seed}")
    for ph in t:
        print(f"  {ph}: n={t[ph]['n']} d={t[ph]['defectives']} p={t[ph]['defectives']/t[ph]['n']:.4f}")
    print(f"  occurrences={occ_tot} table={table}")


if __name__ == "__main__":
    main(sys.argv[1] if len(sys.argv) > 1 else ".")
```
